# FreshMart - Organic Food & Grocery E-Commerce Template 🥬🍎

**FreshMart** is a modern, clean, and fully responsive HTML5 e-commerce website template specifically designed for organic food stores, fresh farm produce shops, grocery markets, and natural food vendors.

---

## ✨ Features

- **Multiple Home Page Layouts**: 5 different homepage designs tailored for organic & fresh food stores.
- **Product Listing Options**:
  - Grid View (Full Width, Left Sidebar, Right Sidebar)
  - List View (Left Sidebar)
  - Detailed Product View pages
- **E-Commerce Flow Pages**:
  - Shopping Cart (`product-cart.html`)
  - Checkout Page (`product-checkout.html`)
  - User Login (`user-login.html`) & Register (`user-register.html`)
- **Blog Section**: Multiple blog list and detail pages for organic food tips & news.
- **Informational Pages**: About Us (`page-about-us.html`), Contact (`page-contact.html`), 404 Error Page (`page-404.html`).
- **Fully Responsive**: Optimized for desktops, tablets, and mobile phones.

---

## 🛠️ Built With

* **HTML5 & CSS3** - Clean semantic markup & modern custom styling
* **Bootstrap** - Responsive layout framework
* **jQuery** - Interactive UI scripting
* **FontAwesome & Material Design Icons** - Icon sets
* **Nivo Slider & Owl Carousel** - Dynamic hero banners and product carousels

## 🚀 How to Run Locally

### Option 1: Live Server (VS Code)
1. Open the project folder in VS Code.
2. Right-click `index.html` and select **Open with Live Server**.

### Option 2: Python HTTP Server
Run the following command in your terminal inside the project directory:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.
